# 00.base.md — 通用设计基础规范

> **这是一份协议，不是某个产品的文档。** 只写终态规则，不含任何产品的实现现状、迁移计划、审计数据或修订记录。
> 本文件只收「与框架无关」的规则。凡涉及 shadcn/ui、Tailwind CSS v4、Ant Design 的版本、MCP、导入方式与 Token 桥接，见 `01.shadcn-ui+tailwindcss+ant-design.md`。
> 框架规范可在此基础上加严，**不得放宽**。违反任一条视为错误，必须在提交前修正。

## 1. 样式书写规范（C1–C10）

以下 10 条对新增与改动一律生效。

**C1 禁止泛元素选择器，禁止用元素做后代选择器**

```css
/* ✗ 依赖 DOM 结构：插一层 wrapper、把 button 换成 a，样式静默失效 */
.segmented button:hover { color: var(--text); }
.settings-nav a.is-active { color: var(--brand-2); }
.form-row input:focus { border-color: var(--brand); }

/* ✓ 元素自己带语义 class */
.segmented-item:hover { color: var(--text); }
.settings-nav-link.is-active { color: var(--brand-2); }
.form-input:focus { border-color: var(--brand); }
```

元素选择器特异性低又不可控，覆盖不住时唯一出路是叠 `!important`——这正是不敢改样式的起点。
允许「容器 class + 组件 class」两级（见 C3，如 `.drawer .btn`），但**任何一级都不能是元素名**。

**C2 禁止用结构伪类定位不同角色**

```css
/* ✗ 换 DOM 顺序即破 */
.setting-row > div:first-child { ... }
.shortcut-list > div:last-child { border-bottom: 0; }

/* ✓ */
.setting-row-label { ... }
.shortcut-list-item:last-child { border-bottom: 0; }
```

伪类只允许用于**同一类元素的节奏**（如 `.wave-bar:nth-child(3n)` 做配色韵律），不得用来区分角色。

**C3 选择器深度 ≤ 2 层，特异性 ≤ (0,2,0)**

- 单 class 优先；修饰符用复合选择器 `.btn.primary`，这就是上限。
- 需要上下文时只允许「容器 class + 组件 class」一层，不得再往下写。
- 禁止 `#id` 选择器、禁止标签限定（`.card section`）、禁止三层后代链。

**C4 禁止 `!important`**

覆盖不生效时按顺序排查：层序（`@layer`）→ 特异性 → 变量 → 组件变体。
都不行说明抽象选错了，改结构而不是加权重。

**C5 基础重置放 `@layer base`，用 `:where()` 把特异性归零**

```css
@layer base, components, overrides;

@layer base {
  :where(button, input, select, textarea) { font: inherit; color: inherit; }
}
```

`:where()` 内特异性为 0，重置永远压不过任何 class，也就不需要 `!important`。
组件规则放 `components`，页面级一次性调整放 `overrides`。

**C6 颜色只用 token 或 `color-mix()`**

- 正文、背景、描边只用语义变量；不写 `#hex`。
- `#fff` 仅允许作为品牌色/危险色底上的文字色。
- 阴影允许 `rgba()`，但必须收敛成 `--shadow-*` 变量，不在规则里散写。
- **一个产品只用一套色空间**（统一 `oklch()` 或统一 `#hex`），不要两套并存。

**C7 禁止内联样式（动态值除外）**

- 允许：进度条宽度、波形峰值高度、拖拽位移等**运行时计算值**，并注释来源。
- 禁止：字号、颜色、间距、边框等静态值写进内联 `style`。

**C8 一个 class 只对应一个角色**

容器用 `-body / -list / -text`，控件用 `-button / -action`。
同一个 class 既当容器又当控件，必然出现"容器被控件的高度裁切"这类 bug。

**C9 不留重复定义块**

同一选择器出现两次必须合并；响应式重定义除外，但只能写在对应断点块内。
合并前先确认后者不是补丁式覆盖——补丁式覆盖应改为修改变体本身。

**C10 声明书写顺序**

- 定位 → 盒模型 → 排版 → 视觉 → 交互：`position/z-index` → `display/width/height/padding/margin/gap`
  → `font/line-height/letter-spacing` → `background/border/shadow` → `transition/animation`。
- 一行一属性；单条规则超过 4 个属性必须换行。

### 1.1 自查方法

```bash
# 搜裸标签选择器（含 > div / 后代标签）
grep -nE '^\s*\.[a-z-]+[^{]*\s(>?)\s*(div|span|p|b|i|a|ul|li|h[1-6]|svg|code|img|button|summary)\s*[,{]' src/**/*.css
```

期望输出为空。命中即需改为角色 class，并同步在组件里补上对应 class 名。

**改选择器必须双向核对**：只改 CSS 不改标记，样式会**静默失效**（页面不报错、元素只是没了样式）。
重命名 class 后跑一次孤儿检查：

```bash
# 列出只存在于 CSS、标记文件中找不到的 class —— 多半是改名后忘了同步，或死代码
python3 - <<'EOF'
import io, glob, re
css = ''.join(io.open(f, encoding='utf-8').read() for f in glob.glob('src/**/*.css', recursive=True))
js = ''.join(io.open(f, encoding='utf-8').read() for f in glob.glob('src/**/*.{tsx,jsx,vue,svelte}', recursive=True))
js += io.open('index.html', encoding='utf-8').read()
classes = sorted(set(re.findall(r'\.([a-z][a-z0-9-]+)(?=[\s,{:.\[])', css)))
print('孤儿 class:', [c for c in classes if c not in js] or '无')
EOF
```

判定：**真孤儿 → 删掉**；**误报 → 放行**（框架层配置项、第三方运行时注入的 class、`data-*` 属性选择器）。

## 2. 颜色与 Token

- 颜色、圆角、阴影、字号、间距必须是**有名字的 token**，在页面里不出现裸值。
- 主题切换（暗色/高对比）只改 token 定义，不在页面里逐处调。
- 覆盖不生效时的排查顺序固定为：层序 → 特异性 → 变量 → 组件变体（同 C4）。
- 暗色主题下所有文字与背景的对比度必须**重新校验**：正文 ≥ 4.5:1，大字与图形 ≥ 3:1。
- 状态色（成功/警告/危险/信息）只用于表达状态，不用于装饰。

## 3. 尺寸与间距：4px 网格

固定尺寸与间距统一使用 **4px 基准网格**；页面级节奏优先取 8px 的倍数，形成 4px 细调、8px 主节奏的层级。

适用范围：

- `padding`、`margin`、`gap`、固定 `width` / `height`、圆角、图标容器尺寸，取 4 的倍数：
  4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px。
- 组件内部密集排列用 4px 步进；区块之间用 8 / 16 / 24 / 32px 拉开层级。
  避免 6 / 10 / 14px 这类「看起来差不多」的间距。
- 表单标签与控件、开关与文字标签之间统一用 8px；小图标与文字之间可用 4px。
- 工具类写法优先用标准步进（1 单位 = 4px）；避免 `7px` / `10px` 这类任意值。

允许的例外：

- 1px 描边、0.5px 分隔线、焦点环等渲染细节，不计入布局间距。
- 紧凑控件内部的 2px 光学内边距可保留，用于让滑块/图标在轨道内视觉居中。
- 字体大小不强制 4px 倍数，按语义档位取值，最小 9px（见 §4）。
- 资产固有尺寸（应用图标、图片、iframe 播放器）不受限制；其外层容器仍按 4px 网格布局。

必须偏离网格时，在代码注释或 PR 说明里写清原因，不能默默使用随意值。

**常用取值（默认值，产品可整体等比调整）**

| 项 | 值 |
|---|---|
| 页面内边距 | 24/28/32px |
| 内容最大宽度 | 按信息密度决定；宽表类可到 1280px |
| 卡片内边距 | 12或16px |
| 表格行高 | 48px（密集表可 36或40px，但字号必须同步 ≥12px） |
| 工具栏控件高 | 等于按钮默认档（28px） |

**圆角阶梯（最多 3 档，超过说明抽象过细）**

| 值 | 用途 |
|---|---|
| 4px | 控件：按钮 / 输入框 / 图标按钮 / 分段控件 / 小标签：chip / `kbd` / 状态徽标|
| 8px | 卡片 / 面板 |
| 12px | 窗口 / 浮层外壳 |

**阴影**：只用于窗口与浮层；卡片以 1px 描边为主，避免「每个卡片都浮起来」。

设计依据：

- [The 8-Point Grid（Spec.fm）](https://spec.fm/specifics/8-pt-grid)：用 8 的倍数定义尺寸、padding 和 margin。
- [IBM Carbon 2x Grid](https://www.carbondesignsystem.com/building-blocks/foundations/2x-grid/overview)：以 8px mini unit 为基本单位。
- [Material Design 3 · Grids & spacing](https://m3.material.io/foundations/layout/grids-spacing/spacing)：以 4 / 8dp 为基准的 spacing 体系。

## 4. 字号规范（Type scale）

字号不按 4px 网格走，按**语义档位**走。全部整数像素，**最小 9px**，不使用 9.5 / 10.5 / 11.5 / 12.5 / 13.5 这类半档。

| Token | 值 | 使用场景 |
|---|---|---|
| `--text-2xs` | **9px** | **极小标注**：状态标记、`kbd` 快捷键、mono 的 ID/路径/序列号、时间戳、括号备注 |
| `--text-xs` | **10px** | **元信息**：表格次要列、字段说明、卡片脚注、进度百分比、单位后缀 |
| `--text-sm` | **12px** | **控件与列表正文**：按钮、输入框、下拉、表格正文、列表主信息、导航项、分组眉标、行内标签 |
| `--text-base` | **13px** | **页面正文**：`body` 基准、段落、页面描述、卡片标题 |
| `--text-md` | **14px** | **强调标题**：顶栏标题、品牌名、区块标题 |
| `--text-lg` | **16px** | **页面级标题**：弹窗 / 抽屉标题、空状态主文案 |
| `--text-xl` | **20px** | 展示级：统计数字、小标题 |
| `--text-2xl` | **24px** | 展示级：指标数字、区块大标题 |
| `--text-3xl` | **30px** | 展示级：单个大读数 |
| `--text-4xl` | **44px** | 展示级：主视觉数字 |

设计意图：9 / 10 是「辅助」层，12 是「操作与阅读」层，13 是「正文」层，14 / 16 是「标题」层，20+ 是「展示」层。
一屏内最多出现 4 档，层级差异靠**字重 + 颜色 + 间距**表达，不靠 0.5px 的字号差。

规则：

- **9px 是硬下限**，内联样式同样适用。低于 9px 一律视为错误。
- 9px 只用于「不承担主要信息」的标注，且必须同时满足：对比度 ≥ 4.5:1、
  `letter-spacing` `.06em`–`.16em`、非连续长文本。
- **正文与交互控件不低于 12px**：任何可点、可输入、需要连续阅读的文字不得用 9 / 10px。
- 相邻档位差 1px 时，必须同时改变字重或颜色，否则用户分辨不出层级。
- 小字靠 `letter-spacing` + 字重 + 对比度提升可读性，**不靠继续缩小字号**。
- 改字号必须同时检查容器高度与行高：字号变大而容器固定，会出现裁切或贴边。
- 不使用 `rem` / `em`（缩放由窗口控制），统一 `px`。
- 展示级只用于单个数字或主视觉文案，不得进入正文段落。
- **禁止硬编码字号**：一律用 token；调整整体字体尺度只改 token 定义，不在页面里逐处调。

## 5. 可点击元素

- 可点击的 `button`、链接、`[role="button"]`、行与卡片统一 `cursor: pointer`；禁用态用 `not-allowed`。
- 整行/整卡可点击时，点击区域覆盖整行/整卡，不要让用户只能点中内部文字或图标。
- 可点击元素必须有 hover 反馈（背景、边框或颜色变化），不能只依赖手型。
- 按钮内不再嵌按钮；使用 `role="button"` 时补齐键盘 Enter/Space 行为。
- 原生 `<button>` 不写 `border` 时可能带入 UA 默认边框；只画单边边框时显式清零其他边。

## 6. 按钮系统

**变体：三档，语义固定**

| 变体 | 用途 |
|---|---|
| `primary` | 每个视图唯一的主行动 |
| `secondary` | 并列的次级行动 |
| `ghost` | 卡片右上、列表行内、取消等低频操作 |

危险操作沿用 `secondary` / `ghost` 外形 + 危险色着色，**不新增第四种变体**。
破坏性操作是当前主行动时（如确认弹窗的删除）才用实心危险色；行内次要动作只着色不加实底，
否则实心红会抢走同行主操作的视觉权重。

**尺寸：只由按钮组件定义，调用处不得覆写**

| 档位 | height | font-size | radius | icon | padding | 用途 |
|---|---|---|---|---|---|---|
| 默认 | 28px | 12px | 4px | 12px | `0 12px` | 页面主次操作 |
| `sm` | 24px | 12px | 4px | 12px | `0 8px` | 表格行内、工具栏密集处 |
| `icon` | 28×28 | — | 4px | 14px | `0` | 顶栏、卡片角、纯图标操作 |

- `sm` 只缩高度与内边距，**不缩字号**，避免多出第五档。
- 图标按钮的图标就是内容，固定 14px（比文字按钮的 12px 大一号，否则在 28px 方块里显小）；
  单个图标操作不要用文字按钮承载。
- **同一行控件必须同高**：`input` / `select` / 按钮 / 图标按钮统一 28px。
- 密度用变量表达（如 `--control-h` / `--control-h-sm`），各档位只引用变量；调整整体密度只改一处。
- 禁止在调用处覆写颜色、边框、高度、字号、圆角；需要不同尺寸时新增档位，而不是就地覆盖。
- 按钮高度变化会改变行高，改档位后必须复核承载它的行/工具栏固定高度。

**状态**

- hover/disabled 行为随变体统一：ghost hover 用**品牌色浅底** + 前景色加深；
  主/次按钮 hover 只改变背景。不要用中性灰做 ghost hover——在已 hover 的表格行上会与行底色重合而看不见。
- 禁用态不另造样式：视觉等同 `secondary`（中性底 + 次要文字色），在组件里定义一处即可。
  **禁止用 `opacity` 表达禁用**——半透明会让下方内容透出来。
- 光标由全局 `@layer base` 统一处理，不在组件里逐个写；组件 base 必须有 `border-0` 清掉 UA 默认边框。

**结构**

- 原生 `<button>` 只用于分段控件、tab、可点行等结构性场景，**且必须挂语义 class**。
- 全局基础样式（`font: inherit` 等）必须放在 `@layer base`，否则会压过工具类，
  造成「按钮字号看起来不对」。

## 7. 表单与输入

- 标签与控件同高对齐；同一表单行的控件高度一致（见 §6）。
- 校验错误就近显示在控件下方，不用弹窗承载字段级错误。
- 占位符不承担标签职责；标签必须常驻。
- 敏感输入（密钥、令牌）：默认掩码，但要能显示完整值、复制、更新；
  宽度至少容纳 240px 等宽文本，不要做成挤在一起的小标签。
- 复选框 / 单选框：选中态用统一品牌色填充 + 对勾，未选中态只留描边。
  **禁止依赖 `accent-color`**——不同区域会出现原生蓝，且无法跟随主题。

## 8. 容器与内容防贴边

- **一个 class 只对应一个角色**（同 C8）：容器与控件不得共用类名。
- **文字容器不要写固定 `height`**：用 `padding` + `min-height` 让内容撑开；
  固定高度只用于单行控件（输入框、按钮、tab）。
- 卡片/列表/引导行的内容与边框至少保留 **8px** 内边距；`border` 不计入 padding。
- 自查方式：DevTools 里比较最后一个子元素的 `bottom` 与容器 border box 的 `bottom`，
  差值应 ≥ `padding-bottom`（含 1px 边框则为 padding + 1）。
- 出现「文字贴边/被裁切」时，先查 class 是否被复用、是否有固定高度，再调间距。

## 9. 对话框与浮层

- 弹窗 body 左右内边距统一 **20px**，与 header / footer 对齐；小尺寸弹窗可用 16px。
- 列表、步骤、代码块在弹窗内必须使用同一内边距，禁止贴边。
- 同一弹窗里的复制类、次要类操作集中放在 footer，使用同一变体，不散落在正文步骤里。
- 高度随内容自适应；超出视口时 body 滚动，header 与 footer 固定。
- 必须同时支持遮罩点击关闭与 `Esc` 关闭；关闭后焦点回到触发元素。

## 10. 图标与图表

- 图标只用一套线性图标库，不混用多套风格；**不用 emoji 充当图标**。
- 图标尺寸跟随控件档位（见 §6），不在调用处写任意宽高。
- 图表优先用 CSS / SVG 自绘（占比条、波形、进度分布）；只有需要坐标轴、缩放、图例交互时才引入图表库。
- 图表同样只用语义颜色 token，暗色主题下必须重新校验对比度。

## 11. 动效

- 时长固定几档：页面/抽屉 180ms、弹窗 160ms、进度条 250ms。同一产品内只用这几个值，不逐处调。
- 只过渡 `transform` / `opacity`，不动 `width` / `top` / `height` 等触发布局的属性。
- 尊重 `prefers-reduced-motion`：关闭位移、缩放与循环动画，保留必要的状态切换。
- 不使用常驻装饰动画；确有需要时做成可关闭的开关。

## 12. 交互复用

- 新增 tab、tab panel、弹窗、抽屉、表格、空状态前，先确认已有实现（设计稿与生产组件）。
- 相同交互的尺寸、间距、选中态、键盘/ARIA 行为必须一致；差异只允许来自内容，不允许来自实现者。

## 13. 提交前自检

1. 搜索 `font-size: [0-9]` 与 `fontSize`：裸值改 token，<9px 一律上调（§4）。
2. 搜索 `p-[`、`m-[`、`gap-[`、`padding: 1[0-9]px` 等任意值：改 4px 倍数标准步进（§3）。
3. 搜索 `> button`、` input`、` a:`、`> div:first-child`：改语义 class（§1 C1/C2）。
4. 搜索 `!important`：零容忍；每条都要消除而不是解释（§1 C4）。
5. 搜索 `bg-[#`、`text-[#`、`style={{ color:`：改语义 token（§1 C6/C7）。
6. 检查圆角档位：全仓出现的圆角值不应超过 4 种；按钮/输入必须同档（4px）。
7. 检查按钮覆写：只允许布局属性（gap / flex / width）出现在容器侧规则里（§6）。
8. 检查动效时长是否来自既定几档；`prefers-reduced-motion` 是否覆盖（§11）。
9. 检查间距与容器：文字容器无固定高度、内边距 ≥ 8px（§8）。
10. 检查弹窗：body 内边距 20px、操作集中 footer、`Esc` 与遮罩均可关闭（§9）。
